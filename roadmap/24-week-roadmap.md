# 🗺️ AI Engineering Learning Roadmap

Rekomendasi urutan belajar dan *deliverable* selama 24 minggu.

## 📅 1. Minggu 1–4: Programming Fundamentals
- **Materi:** Python, functions, OOP dasar, exception handling, Git, environment management, dan SQL.
- **Target:** Python fundamentals

## 📊 2. Minggu 5–8: Data Science & Data Engineering Basics
- **Materi:** NumPy, Pandas, data cleaning, EDA, visualisasi, dan statistik.
- **Target:** Sensor data analysis

## 🤖 3. Minggu 9–12: Machine Learning
- **Materi:** Supervised learning, classification, regression, model evaluation, feature engineering, dan scikit-learn.
- **Target:** Predictive maintenance model

## 🚀 4. Minggu 13–16: Backend & Deployment
- **Materi:** FastAPI, REST API, Pydantic, testing, logging, dan model serving.
- **Target:** ML model as API

## 🧠 5. Minggu 17–20: LLM & RAG
- **Materi:** LLM API, embeddings, vector search, chunking, retrieval, prompt engineering, dan evaluasi RAG.
- **Target:** Engineering RAG Assistant

## 🛠️ 6. Minggu 21–24: AI Agents & Capstone
- **Materi:** Tool calling, agent workflow, state management, error handling, dan integrasi seluruh komponen.
- **Target:** Capstone Project
